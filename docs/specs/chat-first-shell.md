# Spec：对话优先外壳与设置中心（Chat-First Shell & Settings Hub）

> 状态：待实施（ready-for-agent）。来源：2026-11-01 设计讨论——对齐 ChatGPT / Claude / Codex 桌面端的「对话优先 + 配置收纳」模型。

## Problem Statement

用户打开应用后看到的是一个七项并列的主导航（对话 / Agents / Agent 团队 / Skills / MCP 服务 / 模型配置 / 设置），对话被挤成其中一个普通页面。找一条历史对话要在「对话」页里翻一个无分组的平铺列表；而低频的管理操作（建 Agent、配模型、挂 MCP）却占据了最高层级。这与主流 AI 桌面端（ChatGPT、Claude、Codex）「左侧即对话、配置收进设置」的心智模型不一致，新用户需要先理解一整套页面结构才能开始第一次对话。

## Solution

- **启动即对话**：删除主导航栏，最左列直接是可折叠的对话列表（新对话、搜索、分组列表、置顶/归档、底部工具区）。
- **对话自动分组**：默认按时间分组（置顶 → 今天 → 昨天 → 7 天内 → 更早 → 已归档），并可切换为按项目分组（以工作区根目录为键，对齐 Codex 的项目分组）。
- **设置中心**：Agents、Agent 团队、Skills、MCP 服务、模型供应商五个管理页全部收纳进一个标签页式设置中心（与现有通用/知识库/数据设置同处），通过齿轮按钮、快捷键、@ 浮层、模型选择器、空状态引导等快捷入口到达。

## User Stories

1. As a 桌面端用户, I want to 启动应用就直接看到对话列表, so that 我不需要先理解导航结构就能继续上一次工作。
2. As a 桌面端用户, I want to 点「新对话」立即获得一个可输入的直聊会话, so that 提问没有任何前置步骤。
3. As a 桌面端用户, I want to 用一个按钮（或快捷键）折叠对话列表, so that 长回答阅读时有更大的内容宽度。
4. As a 折叠了侧栏的用户, I want to 折叠状态在重启后保持, so that 不必每次打开都重新展开/收起。
5. As a 多会话用户, I want to see 对话按「置顶 / 今天 / 昨天 / 7 天内 / 更早」自动分组, so that 我能按时间直觉定位最近用过的对话。
6. As a 多会话用户, I want to see 已归档会话折叠收纳在列表末尾并可展开, so that 归档不干扰日常视野但随时可找回。
7. As a 用户, I want to see 置顶会话始终排在列表最上方（跨组优先）, so that 最重要的对话永远一步可达。
8. As a 用户, I want to 在对话列表顶部搜索框中按标题与摘要过滤全部会话, so that 会话多时也能秒找。
9. As a 用户, I want to 悬停会话项时直接执行置顶 / 归档 / 重命名, so that 整理列表不需要进入二级菜单。
10. As a 用 WorkBuddy 做编码任务的用户, I want to 切换「按项目分组」让会话按其工作区目录聚合, so that 我能按项目而非时间回顾工作。
11. As a 按项目分组的用户, I want to see 显式选择过工作区的会话以目录名成组（悬停显示完整路径）, so that 项目边界一目了然。
12. As a 按项目分组的用户, I want to see 自动任务目录与直聊会话归入「默认项目」组, so that 列表不会因为每个会话的独立任务目录而碎片化。
13. As a 用户, I want to see 分组偏好（时间/项目）在重启后保持, so that 不必反复切换。
14. As a 用户, I want to 在分组头之间快速滑动定位（组名固定样式、组内按最近更新排序）, so that 长列表仍有秩序。
15. As a 用户, I want to 从对话列底部的齿轮打开设置中心, so that 配置有一个统一入口。
16. As a 用户, I want to 用快捷键（⌘,）打开设置、Esc 或返回按钮回到对话, so that 配置与对话之间一键往返。
17. As a Agent 作者, I want to see Agents / Agent 团队 / Skills / MCP 服务 / 模型供应商在设置中心以标签页呈现, so that 全部管理功能仍然可达且结构清晰。
18. As a 正在对话的用户, I want to 在 @ 浮层底部点「管理助手与团队…」直达设置对应标签, so that 提到不存在的助手时能就近创建。
19. As a 正在对话的用户, I want to 在模型选择器下拉底部点「管理模型供应商…」直达模型配置标签, so that 换模型/加供应商不离开当前会话上下文。
20. As a 新用户, I want to see 空状态与欢迎引导直接把我带到设置对应步骤, so that 首次配置路径最短。
21. As a 键盘用户, I want to 保留 ⌘N（新对话）/ ⌘K（聚焦输入框）/ ⌘F（会话内搜索）并新增 ⌘B（折叠对话列）, so that 全流程可以不碰鼠标。
22. As a 用户, I want to see 主题切换、帮助、版本号收纳在对话列底部与设置「关于」, so that 全局功能不再占用导航层级。
23. As a 用户, I want to 点击会话头部的「直聊 / Agent / 团队」徽标直达设置中对应实体（延伸目标）, so that 查看当前会话所用配置零跳转成本。
24. As a 回归测试者, I want to 视觉桩中预置跨多天、含显式工作区、置顶与归档的会话夹具, so that 分组与设置行为可以在浏览器中完整走查。

## Implementation Decisions

- **壳布局**：根布局从「导航栏 + 会话列 + 主区」三列改为「对话列 + 主区」两列；全局页面状态从七个导航键收敛为「对话 / 设置」两个视图，设置支持携带初始标签打开。原导航栏上的主题切换、帮助按钮、版本信息迁移到对话列底部（主题/帮助）与设置「关于」标签（版本）。
- **对话列折叠**：头部折叠按钮 + ⌘B 切换；折叠后主区左上出现浮动展开按钮；折叠状态持久化为设置字段。
- **时间分组（默认）**：以会话更新时间的本地时区分桶：置顶（跨组置顶）→ 今天 → 昨天 → 7 天内 → 更早 → 已归档（默认折叠，可展开）。组内按更新时间降序。跨午夜的会话按其更新时间所在桶归属，不做动态漂移。
- **项目分组（切换项）**：分组键为「有效工作区根」——会话显式设置过工作区目录时以该目录为键，组名取目录名、悬停显示完整路径；自动创建的任务目录（位于全局工作区的 tasks 子目录下）与未设工作区的会话一律归入「默认项目」。组间按组内最新会话时间降序。严禁以会话级任务目录为键（每个会话一个目录，会碎片化）。
- **分组偏好持久化**：设置新增两个字段——分组模式（time / project，默认 time）与对话列折叠（布尔，默认 false）。沿用现有设置的默认值规范化模式；旧配置文件缺省回落默认，无需迁移。列表过滤搜索与分组正交：过滤生效时仅显示非空组。
- **设置中心**：设置页重构为「左标签导航 + 右内容」两栏，标签为：通用、模型供应商、Agents、Agent 团队、Skills、MCP 服务、知识库、数据与存储、关于。五个管理页内容组件化后作为标签内容复用（页面逻辑不变，仅容器迁移）；现有通用/知识库/存储卡片迁入对应标签。
- **快捷入口**：@ 候选浮层底部加「管理助手与团队…」；模型选择器下拉底部加「管理模型供应商…」；聊天空状态与欢迎引导按钮直达设置的对应标签（设置视图接受初始标签参数）；会话头部徽标点击直达对应 Agent / 团队为延伸目标，允许后置。
- **键盘**：⌘N / ⌘K / ⌘F 行为不变（打开/聚焦对话）；新增 ⌘, 打开设置、⌘B 折叠对话列；Esc 从设置返回对话；帮助面板的快捷键表同步更新。
- **后端**：仅设置模型增加上述两个字段（含默认值与规范化），会话存储、会话 RPC、导出脱敏行为均不变；绑定重新生成（不得手改）。
- **视觉桩**：夹具扩展为跨多天、含显式工作区、置顶、归档的会话集合，覆盖两种分组模式与设置全部标签的走查。

## Testing Decisions

- 只测外部行为，不测实现细节：给定会话集合与固定「当前时间」，断言分组函数的组顺序与成员归属（时间桶边界、置顶跨组、归档折叠、项目键归并规则）；给定旧配置 JSON，断言新字段默认值与规范化结果；UI 行为（两列布局、折叠持久化、标签切换、快捷入口跳转、搜索与分组正交）以真实渲染走查验证。
- 测试缝（全部复用现有缝，不新增）：
  1. **分组/排序纯函数**——放入前端工具库，用 vitest 表驱动测试；先例：现有 chatUtils 纯函数测试。
  2. **浏览器桩全量走查**——`npm run stub`（端口 9246）+ 种子夹具 + 事件注入，覆盖布局几何与交互；先例：直聊会话轮的桩走查与「输入框被顶出窗口」的几何测量法。
  3. **设置字段默认值**——Go 配置存储测试；先例：现有配置存储测试用例。
  1、2 为主缝；3 仅覆盖 schema 变更。若实现中发现需要新缝（如组件级交互测试），应先回到本 spec 修订而不是就地引入。

## Out of Scope

- 以会话级任务目录为分组键；手动拖拽排序或自定义分组成员。
- 分组头的独立折叠持久化；跨设备同步分组偏好。
- 设置多窗口化（独立 Wails 窗口）；任务结果区与行级 diff 相关改动。
- 会话内搜索（⌘F）与历史渲染行为改动；移动端 / 窄窗口响应式。
- 多语言；A2A 发布界面的结构调整。

## Further Notes

- **实施顺序**：第一轮——两列外壳、对话列升级、时间分组、折叠持久化；第二轮——设置中心标签化、五个管理页迁入、全部快捷入口、项目分组切换。每轮按仓库约定在迭代日志顶部追加记录（依据、实现要点、测试证据）。
- **关键澄清（讨论结论）**：「按目录分组」的键必须是工作区根/项目而非会话任务目录——因为每个新会话都会自动创建独立任务目录，逐目录分组等价于逐会话分组。
- **风险与缓解**：老用户的页面导航肌肉记忆（Agents 等不再是一级页面）→ 保留 @ 浮层、模型选择器、空状态三类快捷入口 + 帮助面板说明；设置内容变长 → 左标签锚点导航；绑定重生成会覆盖手改 → 全部通过再生成流程。
- **回归防线**：本轮之前刚修复过「消息区溢出导致输入框被顶出窗口」的布局缺陷（ScrollArea 缺 overflow-hidden），两列外壳改动必须复跑该场景的几何走查（长对话 + 折叠/展开两种侧栏状态）。
